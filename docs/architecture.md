# FarmAI Architecture

## Overview
FarmAI is an AI and IoT-based smart livestock management platform designed to improve animal health, reduce preventable losses, and support data-driven farming practices. The system bridges the gap between rural farmers and modern livestock healthcare services in Bangladesh.

## System Components
The ecosystem consists of two major components:
1. **FarmAI Mobile Application**: An AI-powered app for farmers, veterinarians, and administrators.
2. **FarmAI Smart Collar Hardware**: A wearable IoT collar providing GPS tracking, activity monitoring, and reminders.

## Technology Stack

### Mobile Application
- **Framework**: Flutter
- **Language**: Dart

### Backend
- **Framework**: Spring Boot
- **Language**: Java

### Database
- **RDBMS**: MySQL

### Artificial Intelligence
- **Computer Vision**: CNN Image Classification Model
- **Speech Recognition**: Whisper Speech-to-Text
- **Language Model**: Gemma Large Language Model

### IoT Hardware (Smart Collar)
- ESP32 Microcontroller
- GPS Module
- Motion Sensor
- Solar Charging Module
- Rechargeable Battery
- LED Indicator

### Cloud Services
- Firebase Notification Service
- Cloud Storage
- REST APIs
